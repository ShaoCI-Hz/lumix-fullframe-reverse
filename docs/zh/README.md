## 研究路线

```text
取得公开固件更新包
      ↓
解析 UPD 容器格式 (02)
      └─→ 文件头 / 分区表(58 项)/ 校验 / 签名布局
      ↓
分析加密与完整性保护 (03)
      ├─→ 数据分区:强对称加密,每机型·每分区独立密钥
      ├─→ 完整性:CRC32 + 逐分区 SHA-256 + ECDSA P-256
      └─→ 只读分析下不暴露明文
      ↓
转向 USB / PTP 协议层 (04 → 05)
      ├─→ WPD/MTP 接入路径打通
      └─→ 枚举出 3 个厂商私有 opcode(0x9102 / 0x9103 / 0x9104)
      ↓
多机型差分 (06)
      ├─→ 平台演进、构建时间戳解码、机型特有分区
      └─→ S1H 独有 mult_fpga 分区(机型硬件规格差异的反映)
      ↓
镜头固件 (.plf) 解析 (07)
      ├─→ 明文 ARM Cortex-M,加载基址 0x08000000
      ├─→ 头部 = 段描述表;变量表 578 项 = 调试元数据
      ├─→ 各型号独立链接 → 跨型号须用内容指纹
      └─→ 地址无关指纹聚类:6 型号 2,096 个指纹
            ├─ 全型号共享 17 个 = 编译器运行时库
            └─ 仅变焦 20 个   = 候选业务逻辑(命令处理器)
      ↓
跨厂商 L 卡口 (09)
      ├─→ .plf 为 L-Mount Alliance 标准(Sigma / Leica / Samyang 同格式)
      └─→ Sigma 含完整 Cortex-M 向量表,基址 0x45A
```

## ⚠️ 勘误记录

**关于 `07-镜头固件.md`:** 该文档 §11.3 初版曾断言
"加载地址 = 文件偏移",**该推理已被证伪并撤回** —— 区间测试覆盖 98.59% 的文件
近乎平凡,且把普通 `B` 分支误计为函数调用。后续 §19 以 Cortex-M 标准内存映射
重新确定加载基址为 `0x08000000`。详见该文档 §11.3、§11.5、§13.7、§19,
复现脚本见 `../../analysis/lens/verify_claims.py`。

**关于方法选择:** 镜头固件的函数边界依赖所选分析方法。四种方法的
精度 / 召回权衡已在 `07-镜头固件.md` §22–26 中量化记录
(严格集 / 可达性 / 融合 / 结束点切段),部分早期统计结论随之修订。

**关于函数识别的收敛:** 上述自建方法是通往最终答案的准备,而非终点。
把 §22 的 133 个双重验证入口作为**种子**交给 Ghidra 的递归下降后,
函数识别从 1,095 升至 **1,824**(+66.6%),并找回了 226 个
**序言判据结构性无法枚举**的叶子函数。详见该文档 §27。

## 方法说明

- 所有结论均来自对**公开固件更新包**的格式分析,以及对**自有设备**的协议探测
- 未使用任何泄露的厂商资料或未公开文档
- 每项结论都附有验证依据(哈希比对、跨机型对比、结构性检验)
- 分析脚本位于 `../../analysis/`,按 `body/` / `lens/` 分类,可逐条复现

## 固件样本要求

分析需要官方固件更新包。仓库**不包含固件本体**(版权原因),
获取方式见 [01-固件获取.md](01-固件获取.md)。

建议同时准备**姊妹机型**固件用于差分对比:

| 机型 | 文件名 | 用途 |
|---|---|---|
| DC-S5M2X | `S5m2XV27.bin` | 主样本 |
| DC-S5M2 | `S5m2_V37.bin` | 跨机型差分(硬件同源,布局一致)|

> 两机型固件大小完全一致(179,207,168 字节),分区表一一对应,
> 是定位「机型特有代码」的高价值差分样本。

镜头固件可直接下载第三方 L 卡口样本(官方直链):

```bash
python ../../analysis/lens/download_sigma.py
```
