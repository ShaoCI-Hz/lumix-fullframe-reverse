# 多机型固件对比分析

对 6 个 LUMIX 全画幅机型固件的横向对比,用于理解平台演进与机型差异。

---

## 1. 样本清单

| 机型 | 平台代号 | 镜像大小 | 分区数 | 构建时间戳(`+0x24`)|
|---|---|---|---|---|
| DC-S1 | `MC892` | 90,226,176 | 53 | `0x12161150` → 12/16 11:50 |
| DC-S1H | `MC893` | 91,012,608 | 53 | `0x02140907` → 02/14 09:07 |
| DC-S5 | `MC801` | 90,238,464 | 48 | `0x07101450` → 07/10 14:50 |
| DC-S5M2 | `MC8223` | 179,207,168 | 58 | `0x02102018` → 02/10 20:18 |
| DC-S5M2X | `MC8223X` | 179,207,168 | 58 | `0x02102019` → 02/10 20:19 |
| DC-S9 | `MC8259` | 172,915,712 | 55 | `0x05132030` → 05/13 20:30 |

**所有机型**:
- 均为 UPD 容器格式
- 镜像数据全部加密(熵 8.000)
- 均含 64 字节 ECDSA P-256 签名(`+0x220`)

---

## 2. `+0x24` 字段 = BCD 构建时间戳

该字段按 BCD 解码为 `MM/DD HH:MM`:

```text
DC-S5M2   0x02102018 → 02/10 20:18
DC-S5M2X  0x02102019 → 02/10 20:19
```

**S5M2X 仅比 S5M2 晚 1 分钟** → 二者出自**同一构建批次**,
靠机型 ID(`MC8223` vs `MC8223X`)区分功能。这是「靠固件区分机型」的直接证据。

---

## 3. 平台架构:两代完全重构

| 特征 | 老平台(S1/S1H/S5) | 新平台(S5M2/S5M2X/S9) |
|---|---|---|
| 镜像大小 | ~90 MB | ~180 MB |
| `zboot` / `dtb` | ✅ 有 | ❌ 无 |
| **`zimage`(Linux 内核)** | ✅ 2.5 MB | ❌ 无 |
| **`rootfs1` / `rootfs2`** | ✅ 12 MB + 4 MB | ❌ 无 |
| 系统性质 | **嵌入式 Linux** | **RTOS / 自研** |
| `program` | 14–16 MB | **45 MB** |
| `compress_pr` | ❌ | ✅ 16 MB |
| 启动分区 | `postboot1-5`, `dram_sleep` | `boot`, `postboot1_r-5_r` |
| 网络 | `hm_d_nw`(1 个) | `hm_d_nw_1st`~`7th`(7 分片) |
| 图像处理 | `ipu_*`, `rc_*`, `nr_*` | `dsp_kizu_*`, `raw_kizu_*`, `dsp_eisldc_*` |
| 协处理器 | `apu0_code/data_i/e` | ❌ |
| 新增数据区 | — | `kizu_data` `vkizu_data` `lut_data` `lut2_data` `grid_data` `xtk` `pzm_data` |

> 老平台(S1/S1H/S5)是跑 **Linux** 的相机;S5M2 代换成了**完全不同的处理架构**。
> 这解释了 ~90 MB → ~180 MB 的体量翻倍。

## 4. 机型特有分区(功能差异的结构线索)

| 分区 | 出现机型 | 推测含义 |
|---|---|---|
| **`mult_fpga`** | **仅 DC-S1H** | **多功能 FPGA 配置** |
| `lns_fpga` | 仅 DC-S1 | 镜头 FPGA |
| `dsh_adj` | 仅 DC-S9 | 机型专用标定 |
| `apu0_*` | S1, S1H | APU 协处理器 |
| `avchd_info` | S1, S1H | AVCHD 录制元数据 |
| `wifi2_info` | S5M2, S5M2X | 双无线模块 |
| `lut2_data` | S5M2, S5M2X | 第二 LUT 组 |
| `grid_data` | S5M2, S5M2X | 网格线数据 |
| `music` | 除 S9 外全部 | 提示音 |

### 关键观察:**DC-S1H 是唯一带 `mult_fpga` 的机型**

`DC-S1H` 是 LUMIX 全画幅中定位最高的机型,**独家拥有 `mult_fpga` 分区**,
而 S5M2 系列与 S9 均无该分区。

> **推论**:该分区对应 S1H 级别的 FPGA / 图像处理硬件配置,
> 属于机型间**硬件规格差异**在固件布局上的反映。

## 5. 数据分区的机型差异

| 分区 | S5M2/S5M2X | S9 | 说明 |
|---|---|---|---|
| `lut_data` | 2,176 KB | **8,576 KB** | S9 的 LUT 数据是 4 倍 |
| `lut2_data` | 8,576 KB | ❌ 无 | S9 未使用第二 LUT 组 |
| `vkizu_data` | 6,144 KB | **9,216 KB** | S9 更大 |
| `grid_data` | 2,304 KB | ❌ 无 | |
| `wifi_info` | 128 KB | **256 KB** | |
| `music` | 有 | ❌ 无 | |

> S9 把两处 LUT 合并到单一大分区(`lut_data` 8576 KB),并去掉了提示音等分区。
> 注意 `lut_data` / `lut2_data` 在镜像中**逻辑内容为全零**(见 `03-加密分析.md`),
> 说明 LUT 是运行时生成的,固件内不含实际 LUT 数据。

## 6. 复现方式

```bash
# 获取各机型固件(见 01-固件获取.md),放入 firmware/
python tools/pana_unpack.py firmware/S1H__V28.bin --list
# 或使用对比脚本
python analysis/body/multi_model_diff.py
```

分析要点:
- `+0x0C` 机型 ID(平台代号)
- `+0x24` 构建时间戳(BCD)
- `+0x220` ECDSA 签名
- `0x2DC` 起分区表(92 字节/项)
